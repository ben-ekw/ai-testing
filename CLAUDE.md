# CLAUDE.md

- To sign in to Claude Code, run `claude auth login` in a terminal. The `/login` slash command isn't available in this environment.
- When committing, sign off the commit (the equivalent of `git commit -s`, adding a `Signed-off-by:` trailer from the git user's name and email) and add the trailer `Co-Authored-By: LLM` exactly as written, instead of a model-specific co-author line.
